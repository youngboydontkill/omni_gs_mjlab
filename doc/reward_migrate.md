  kuavo_s45_rough_env_cfg() 的链路是：

  make_velocity_env_cfg()              # 基类 reward 表（velocity_env_cfg.py:362）
    → make_kuavo_velocity_env_cfg()    # pop foot_gait、angular_momentum
      → _kuavo_rough_env_cfg()         # 改 pose std / 受控关节 / 添加 self_collisions
        → _apply_s45_emp_rewards(cfg)  # 重写为 Leju-IsaacLab S42 EMP 风格
        → _separate_depth_observations(normalize=True)

  所以「原有 reward」≡ 进入 _apply_s45_emp_rewards 之前 cfg.rewards 的状态（13 项：base
  13 项 − foot_gait − angular_momentum + self_collisions）。

  一句话总结

  _apply_s45_emp_rewards 把项目原有的"MJLab 风格、靠 pose + foot_gait/slip/clearance
  塑形"的 13 项 reward，就地重写为 Leju-IsaacLab S42 EMP 的 27 项：保留 7 项（pose / 
  body_ang_vel / joint_acc_l2 / joint_pos_limits / is_terminated / stand_still / 
  self_collisions）→ 删 3 项（foot_clearance / foot_slip / soft_landing）→ 改 4
  项权重/std（track_linear/angular_velocity、action_rate_l2、body_orientation_l2，方向都
  是「跟踪信号 ↑ + 平滑惩罚 ↓ + 姿态惩罚 ↑」）→ 加 17
  项（torque/power/air-time/slide/stumble/fly/feet_too_near/undesired_contacts +
  默认手臂姿态先验）。注释里的多处 P1: 是后续根据「卡在
  stand-still」的训练观察做的二次回调，把过强的 gait trap（feet_too_near −5→−1、fly
  −10→−2）和过度奖励的姿态先验（track_default_arm_pos 注释提到
  3.0→1.0）压回更温和的水平。
